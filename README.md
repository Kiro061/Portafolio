# Andrés Castellanos — Junior Backend Developer

Portfolio profesional de una sola página construido con HTML5, CSS3 y JavaScript vanilla, orientado a posiciones de **backend y automatización**.

---

## Stack técnico demostrado

- Integración de APIs externas (OpenAI, Telegram, Google Sheets)
- Automatización de procesos con n8n y lógica de decisión con IA
- Manejo de webhooks, flujos asíncronos y servicios de terceros
- JavaScript vanilla con arquitectura modular, sin dependencias ni build tools
- Control de versiones con Git y Conventional Commits

---

## Características del sitio

- **Responsivo** — diseño mobile-first, funciona en móvil, tablet y escritorio
- **HTML semántico** — uso correcto de `header`, `nav`, `main`, `section`, `footer`
- **Accesibilidad (WCAG AA)** — etiquetas ARIA, `focus-visible`, soporte para `prefers-reduced-motion`, contraste de color suficiente
- **Rendimiento** — cero frameworks, cero dependencias externas, carga instantánea
- **Interactividad** — navegación sticky, menú hamburguesa con cierre por teclado, animaciones con Intersection Observer, formulario con validación en tiempo real

---
